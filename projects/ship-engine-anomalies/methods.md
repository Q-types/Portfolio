# Corrected evaluation protocol

The [fixed protocol](../../examples/ship_engine_anomalies/protocol.json) was declared before evaluating the new fixture. All fitting, preprocessing and calibration complete before evaluation. Frozen state is written before evaluation is called. There is one holdout design, no cross-validation, no parameter search, no trimming of fitting rows, and no adjustment based on evaluation outcomes. This is a bounded synthetic test, not a corrected claim about original submission results.

The sensor schema is explicitly frozen at six columns. Means and population standard deviations are fitted on the 96 fitting rows. Z-score channel flags use absolute deviation ≥ 3 population SD; a constant fitting channel flags changed values and leaves unchanged values unflagged. The row rule alerts on any flagged channel. IQR fences are Q1−1.5×IQR and Q3+1.5×IQR; equality is inside. Both any-channel and at-least-two-channel row rules are reported. Central-95% limits are the fitting 2.5th and 97.5th percentiles, inclusive; the selected row rule requires at least two channels outside. Quantiles linearly interpolate at index (n−1)p. Flags are computed on original aligned rows before aggregation; masks retain rows below the declared count and never use the count as an input feature.

Actual SVM and Isolation Forest receive the same six fitting sensors after fitting-only standardisation. SVM uses RBF gamma=0.2, nu=0.05, tolerance 0.001, 10,000-iteration cap and 32 MB cache. Isolation Forest uses 64 trees, 64 samples per tree, all features, contamination=0.05, seed 41 and one job. Every other backend default is exported in frozen state. Both score as **negative decision_function**, with alert if score > 0. Higher means more unusual under that model; it is not a probability, and native SVM and IF score magnitudes are not compared. Predeclared sensitivity fits change only nu to 0.10 or contamination to 0.10. They are diagnostics, not alternative models chosen after evaluation. These parameters are settings, not known fault rates.

Oil pressure is the sole prediction target, in fixture bar gauge. Raw predictors are RPM, fuel pressure, coolant pressure, oil temperature and coolant temperature. The alternative uses RPM², fuel pressure, coolant pressure, oil-minus-coolant temperature and coolant temperature. Dependencies are explicit in code and tested by changing the target while requiring all predictions and features to remain unchanged. Positive RPM and retaining coolant temperature make this a same-information, five-dimensional transformation. Temperature difference is invariant to Celsius/Kelvin reference translation; the retained absolute temperature is an ordinary measured predictor, not a claimed invariant. No Celsius ratios, viscosity constants, VIF selection or symbolic physical laws are asserted.

Each feature set learns a separate scaler from identical fitting rows. Mean prediction uses the fitting target mean. Ridge solves sum of squared errors plus 0.001 times the squared standardised slopes, with an unpenalised intercept. Random Forest uses 48 trees, depth 5, minimum leaf size 3, all features, seed 41 and one job. Both feature sets have exactly one fixed configuration per method. The calibration cohort sets each residual alert threshold at the 95th percentile of absolute error; a later absolute error strictly above that threshold alerts. Calibration does not fit the regressor. Thresholds are empirical settings with a small calibration sample, not probability calibration or guaranteed coverage.

All models evaluate the same 48 IDs. Each ID has an unperturbed control and independently shifted copies (+1.5 bar oil pressure, +12 °C coolant temperature, +200 RPM). Other channels remain unchanged. Injection markers are separate fields from detector alerts. The target-only shift must leave independent predictions unchanged; it changes signed residuals by exactly +1.5 bar. Coolant and RPM interventions can change predictions. These inconsistent sensor changes test sensitivity to the declared manipulation and do not simulate causal engine dynamics.

MAE/RMSE compare pressure predictions in a common target unit. Per-model paired score deltas are computed on matched IDs in that model's own score units. Alert-set Jaccard is intersection/union on the same cohort; two empty alert sets are defined as 1, which conveys no detection evidence. Tables and selected IDs derive from the exact exported records. Parameter Jaccard measures membership sensitivity, not sampling uncertainty. No distances or variances are compared across transformed spaces, and no self-generated detector flags are used as truth for accuracy.

Symbolic regression is pending, so there is no claim of an equivalent executed RF/PySR comparison. Completing it requires a permitted backend and the same target isolation, information, cohorts, preprocessing, budget disclosure and error definitions. A real-data study additionally needs exact input identity, verified units and processing authority, plus independently reviewed fault/event evidence if fault performance is to be claimed.
