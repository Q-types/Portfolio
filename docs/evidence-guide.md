# How to read the evidence

The portfolio connects personal contributions to inspectable evidence while preserving the distinction between completed original work and later demonstrations. Start with a case, follow its result or source links, then use the [reproduction matrix](reproduce.md) if you want to execute the public example.

| Evidence | What it supports | What it does not establish |
| --- | --- | --- |
| Historical notebooks and submitted reports | What the original author did and the findings saved for that version | A fresh run, corrected evaluation or permission to redistribute source data |
| Private implementation assessment | Version-bound mechanisms and the explicitly scoped checks described by the case | Installed service state, deployment, client adoption or measured commercial gains |
| New synthetic examples | Executed, tested mechanics on independently invented inputs; exact manifests and retained failure cases | Original-data results, generalisation, end-to-end answer accuracy or production readiness |
| Bounded review | Review of the stated source/evidence scope and specified replay checks | Approval of every historical claim, original data, live operations or subsequent changes |
