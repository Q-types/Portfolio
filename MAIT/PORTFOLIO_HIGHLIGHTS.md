## 💼 Interview Talking Points

### Technical Decisions

**Q: Why Python?**
- Rapid prototyping for AI/ML applications
- Excellent ecosystem (OpenAI library, ReportLab, etc.)
- Readable, maintainable code
- Strong data processing capabilities

**Q: Why JSON for data?**
- Human-readable for content creators (teachers)
- Version control friendly
- Flexible schema for iterative development
- Easy parsing and manipulation

**Q: Why GPT-3.5 instead of GPT-4?**
- Cost-effectiveness: 10-20x cheaper
- Sufficient quality for lesson planning
- Faster response times
- More sustainable for production use

### Design Decisions

**Q: How did you determine the lesson structure?**
- Research into PGCE best practices (Rosenshine's Principles)
- Analysis of AQA assessment requirements
- Cognitive science (Sweller's Cognitive Load Theory)
- Consultation of teacher training materials

**Q: How do you ensure quality of AI-generated content?**
- Structured prompts with clear requirements
- Context from official syllabus documents
- Pedagogical frameworks baked into prompts
- Multiple output stages for review

**Q: How would you scale this?**
- Web interface for broader access
- Database for lesson plan storage and sharing
- User authentication and personalization
- Analytics dashboard for effectiveness tracking
